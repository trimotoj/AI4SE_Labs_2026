# Week 08 Assignment Guidance

Read the relevant specification in `Assignments/` before starting. Put each task's submission in its own task folder. When the assistant needs a file in a specific location to discover or load it, keep the working file there and point to it from the corresponding task folder.

Keep configuration changes and additions from the exercises in place through the end of the assignment. For Task 9, make a separate redacted copy of the final configuration so the submitted settings correspond to the screenshots. Keep API keys, tokens, passwords, and other secrets out of reports, screenshots, transcripts, tool outputs, and committed files. Check each artifact for sensitive data before saving it to the repository or submitting it.

Record the actions actually performed and the results actually observed, including failures. For exercises that require a live check, use the actual coding assistant and preserve the relevant interaction. If a feature is unsupported and the task allows a fallback, briefly identify the assistant, explain why the feature appears unavailable, and describe the supported alternatives.
